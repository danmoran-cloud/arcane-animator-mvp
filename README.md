# Arcane Animator

A web-based animation editor for creating arcane and magical effects, built with Next.js.

## Features

- Layer-based animation timeline
- Built-in effects browser with base and premium effects
- Asset library
- Export dialog
- Stripe-powered premium subscriptions and coupon system
- Supabase authentication

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- [Next.js](https://nextjs.org) — React framework
- [Supabase](https://supabase.com) — Auth and database
- [Stripe](https://stripe.com) — Payments and subscriptions
- [Tailwind CSS](https://tailwindcss.com) — Styling
- [shadcn/ui](https://ui.shadcn.com) — UI components
